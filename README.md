# Будильники+

Приложение создаёт серию будильников и передаёт их стандартному приложению Android «Часы». Укажи время первого сигнала, количество и интервал; созданные будильники появятся в системном списке.

Каждый сигнал получает метку вида `Будильники+ A1B2 1/15`. Приложение хранит метки, чтобы отправлять системным часам запросы на отмену отдельного будильника или всей серии. Поддержка отмены зависит от приложения «Часы» на устройстве.

Минимальная версия Android — 8.0 (API 26). Используется системное разрешение `SET_ALARM`.

## Скачать APK

Открой вкладку **Actions**, выбери запуск **Build APK** со статусом **Success** и скачай артефакт **ManyAlarms-debug**. Распакуй архив и установи `app-debug.apk`.

Если устанавливаешь эту версию поверх прежней сборки из GitHub Actions, Android может сообщить о несовпадающей подписи. Тогда сначала отмени старые сигналы прежней версии, удали приложение и установи новый APK. Будильники, уже переданные стандартным «Часам», останутся там.

## Исходный проект

Архив **ManyAlarms-project-v3.zip** находится в корне репозитория. Его можно открыть в AndroidIDE или собрать через GitHub Actions.
