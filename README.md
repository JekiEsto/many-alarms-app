# Будильники+

Приложение для создания серии будильников: укажите время первого сигнала, количество и интервал. Список можно изменить или удалить полностью. Сигналы восстанавливаются после перезагрузки телефона. Минимальная версия Android — 8.0.

## Скачать APK

APK собран GitHub Actions в запуске Build APK #3. Откройте вкладку **Actions**, выберите запуск **Build APK #3** со статусом **Success**, внизу страницы в разделе **Artifacts** скачайте **ManyAlarms-debug**. Распакуйте скачанный ZIP и откройте `app-debug.apk` на телефоне. Android попросит разрешить установку приложения для приложения, которым вы открыли APK.

## Собрать ещё раз

1. Откройте вкладку **Actions**.
2. Выберите workflow **Build APK**.
3. Нажмите **Run workflow**, оставьте ветку `main` и подтвердите запуск.
4. Когда появится статус **Success**, откройте запуск и скачайте **ManyAlarms-debug** из раздела **Artifacts**.

Исходники находятся в архиве `ManyAlarms-project-v2.zip` в корне репозитория.
