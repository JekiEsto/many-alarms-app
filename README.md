# Будильники+

Приложение создаёт серии будильников и передаёт каждый сигнал стандартному приложению Android «Часы». Укажи время первого сигнала, количество и интервал; после подтверждения часы добавят будильники в системный список.

Каждый сигнал получает метку вида `Будильники+ A1B2 1/15`. Метки помогают найти сигналы серии и запросить их отмену. Возможность автоматической отмены зависит от приложения «Часы» на устройстве; если оно не поддерживает отмену через системное действие, удаляй будильники вручную в «Часах».

Минимальная версия Android — 8.0 (API 26). Приложение использует системное действие `ACTION_SET_ALARM` и разрешение `SET_ALARM`.

## Скачать APK

Открой вкладку **Actions**, выбери запуск **Build APK** со статусом **Success** и скачай артефакт **ManyAlarms-debug**. Распакуй архив и установи `app-debug.apk`.

Если устанавливаешь эту сборку поверх прежней версии из GitHub Actions, Android может сообщить о несовпадающей подписи. Тогда сначала отмени старые сигналы прежней версии, удали приложение и установи новый APK. Будильники, уже переданные стандартным «Часам», останутся там.

## Исходный проект

Архив **ManyAlarms-project-v5.zip** находится в корне репозитория. Его можно открыть в AndroidIDE или собрать через GitHub Actions.
